# Lab 5 - Connecting with BeeAI Platform

## Agent provider template
Provide a template for creating an agent provider. This template can be used to create a new agent provider repository.
A provider contains one or more agents, and each agent can have one or more tools.
https://github.com/i-am-bee/beeai-provider-starter

You may create a new provider by using the template repository or clone the demo repository.
[AI malware analyst agent](https://github.com/barvhaim/ai-malware-analyst)


Follow the instructions in the README file on AI malware analyst agent repository to set up the environment and run the agent.
